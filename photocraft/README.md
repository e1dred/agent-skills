# PhotoCraft agent skill

An [Agent Skill](https://agentskills.io) for driving the [PhotoCraft](https://github.com/storytold/photocraft) image
editor from an AI agent: the headless `photocraft-cli`, exact command parameter formats, traps and recipes, collected
from real tasks. Part of [agent-skills](../README.md); install with `./install.sh photocraft`.

Tested with photocraft-cli 0.15.1 on Linux. Unofficial. Background reading for what PhotoCraft can do:
[artcraft-skills](https://github.com/midasmatterhorn/artcraft-skills) (MIT, macOS) — referred to, not copied.
