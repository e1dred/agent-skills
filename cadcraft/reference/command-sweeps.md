## Round 13: the remaining command ids (2026-10-26, headless, each probe in its own `cadcraft-cli run`; results read, not rendered)
> **A command that returns nothing prints no line**, so in a batch the "last result" may belong to the previous command: check effects with `entities`/`list`/`layerstate.list`.
- **Draw variants (all returned a handle):** arcs `arc.sce|sca|scl {start,center,end|angle|length}`, `arc.sea|sed|ser {start,end,angle|direction|radius}`, `arc.cse|csa|csl {center,start,end|angle|length}`, `arc.continue {end}` (tangent from the last line/arc); circles `circle.cd {center,diameter}`, `circle.2p`, `circle.3p`, `circle.ttr {h1,p1,h2,p2,radius}`, `circle.ttt {h1,p1,h2,p2,h3,p3}` (the picks choose the solution); `ellipse.axis {p1,p2,distance}`, `ellipse.arc {center,major,ratio,start,end}` or `{p1,p2,distance,start,end}`; `spline.cv {control,degree}`; `revcloud.polygonal {points,arcLength}`, `revcloud.freehand {freehand,arcLength}`; `boundary {points:[inside point]}` made 2 polylines (outer and inner loop); `blend {h1,p1,h2,p2,continuity}`; `measure {handle,length}` (3 points on a 20-long line at 5); `breakatpoint {handle,at}` (two lines, new handles); `reverse {handles}`; `arraypath {handles,path,count}` (returned 4 copies); `mocoro {handles,base,ops:[{copy},{rotate},{scale}]}`; `-block {name,base,handles,keep:"retain"}`; `ncopy {handle:insert,delta}`; `groupedit {name,add}`, `-group {option:"create"|"?",name,handles}`, `pickstyle {}`.
- **Arrays:** `arrayrect` returns ONE associative handle (the array block `*U2`); `arrayedit {handle,cols,rows}` rebuilt it (`*U3`) but the insert does not report columns/rows (`cols:1`), so check the copies with a render. `arraypath` needs the path handle.
- **Dimensions:** `dimordinate {feature,leader}`, `dimjogged {handle:circle,centerOverride,at,jog}`, `dimjogline {handle}`, `dimedit {handles,mode:"new",text:"40 REF"}`, `dimedit.oblique {angle}`, `dimtedit {mode:home|angle|left|center|right,angle}` (+ `dimtedit.home|angle|center|right`; `left` sets override `textJust 1`), `dimoverride {handles,DIMTXT:5}` and `dimstyle.override` (`changed:1, ignored:[]`), `dimstyle.update {handles}`, `diminspect {handles,shape:"round",label,rate}`, **`dimreassociate` only works when geometry sits under the dimension points** (1 of 1 on a drawn line, 0 of 1 on a bare dimension), `dimdisassociate`; `dimstyle.dimension {name,DIM*…}` = `dimstyle`; `dimstyle.list|rename {from,to}|current|delete` and `style.list|rename|current|delete` (not Standard or one in use).
- **Multileaders and others:** `mleaderedit.add {handle,points}` → `added:1`, `mleaderedit.remove {handle,index}`; **`mleaderalign` needs `to` (the multileader to align to) AND `points` (first and last position)** for `distribute|parallel|spacing|current` (`aligned:n`); `mleadercollect {handles,at}` needs two or more multileaders with BLOCK content (`mleader {points,block}`; made `collected:2`); `mledit {tool:"cc",first,p1,second,p2}` joined two crossing mlines; `radius.measure {handle}` (R and diameter), `angle.measure {vertex,p1,p2}` (90°), `quickcalc.pick {mode:"distance",points}` (5), `measuregeom {mode:"area",handle}` (area and perimeter; distance mode wants `p1`/`p2`).
- **Draw order:** `draworder {handles,order:"front"|"back"|"above"|"under",reference}`, `draworder.back|above|under`, `texttofront {objects}` / `.text|.dimensions|.leaders|.all`, `hatchtoback {}`; `entities` lists in draw order and the fronted circle moved to the END of the list. `hatchpick` only returns the picked points/handles for the typed HATCH flow (it creates no hatch: use `hatch`).
- **Constraints:** geometric `gcparallel|gcperpendicular|gccollinear|gcequal|gcvertical|gcfix|gcconcentric|gctangent|gccoincident {h1,p1,h2,p2}` and `gcsymmetric {h1,h2,h3}` (symmetry about a line), `gcsmooth` (two splines), each returned `constraints`, `dof` and a status per object (two free lines = 8 dof; parallel → 7, collinear → 6, one `gcfix` on a start point → 2 for a line); dimensional `dcaligned|dclinear|dcvertical|dcangular|dcradius|dcdiameter {h1,p1,h2,p2,value|expr,name}` (a radius 5 circle became 6.0000000006 after `dcdiameter 12`: the solver is approximate), `dimconstraint {type,h1,value,name}` lists the parameter (`R1 = 8`), `geomconstraint {type,h1,h2}`; `constraints.inspect` gives ids, glyph anchors and `satisfied`; `delconstraint {ids:[id]}` (ids start at 1; id 0 removed nothing), `constraintsettings {infer,barsVisible}`, `constraintinfer {}`, `constraintbar.showall|hideall`, `dcdisplay.showall|hideall`.
- **Layers:** `layer.delete {name}` fails "layer has objects on it" otherwise silent; `laymcur {handles}` makes the object's layer current (CLAYER checked), `laycur`, `laymch {handles,layer}` moved an object to a layer, `laylck|layulk {handles}`, `layon {}`, `laythw {}`, `layuniso {}`, `layerp {}` ("Restored previous layer states"), `layerstate.restore|rename {from,to}|delete {name}|list`.
- **Annotative:** `aiobjectscaleadd|aiobjectscaleremove {handles}` (the current annotation scale; removing keeps at least one), `annoreset`, `annoupdate`, `annovisible.current|all|toggle` (ANNOALLVISIBLE 0/1).
- **Attributes and counts:** `attdisp {mode:"on"|"off"|"normal"}` + `.normal|.on|.off` (ATTMODE 1/2/0), `attsync {name}`, `-attedit {find,replace,block,tag}` changed `hello` to `bye` in one reference only, `eattext {blocks,file}` wrote a CSV (Count, Name, tags), `countlist {}` (per block, `nested`), `counttable {at}` inserts a table of block counts.
- **Tables:** `table.deleterow|insertcol|deletecol|unmerge`, `tabledit {handle,row,col,text}`, `table.break {handle,enabled,direction,height}` (`parts:3`), `tablestyle.cellstyle {name:"Data",textHeight}` (lists the cell styles), `datalink {handle,path:CSV}` (4×2 for a 3-row CSV with the title row) + `datalinkupdate {}` (`updated:1`); `table.formula {handle,row,col,function:"sum"}` and `table.recalc` need rows that exist (a table with a title and header has rows 0..n+1).
- **View and layouts:** `view.set {center,height}` / `view.get` (`viewportPx` 1200×800), `zoom.window {p1,p2}`, `zoom.extents`, `zoom.all`, `zoom.in|out` (×½, ×2), `zoom.object`, `zoom.previous`, `pan.left|right|up|down`, `regen`, `regenall`; `zoom.realtime`/`zoom.dynamic` need a `factor` (they are mouse commands). Layouts: `layout.new {name,viewport:false}`, `layout.set {name|"Model"}`, `layout.copy {from,to}`, `layout.rename {from,to}`, `layout.delete {name}`, `layout.list` (page setup and viewports); `mview.polygonal {points}` → boundary + viewport handles; `vplayer {handle,freeze:[layer]}` → `frozenLayers`; `mspace`/`pspace`; `chspace {handles,to:"L1"}` (`moved:1`); **`vpclip` needs the viewport handle**; `vports.3` etc. report tiles; `vports {count}` in the Model tab fails ("Command not allowed in Model Tab") because it calls `mview`; `vports.activate` needs `index`. `plotwindow {p1,p2}`, `plottermanager {action:"list"}` (built-in CADCraft PDF and PNG devices), `preview {layout,paper,fit,width}` returns a base64 PNG.
- **Settings and queries:** `lweight {lineweight}`, `limits {min,max}`, `ddptype {pdmode,pdsize}`, `-linetype {load}`, `hatch.patterns {}` (standard names ANSI31…, GRASS…), `time {}`, toggles `ortho|grid|otrack|dynmode|lwdisplay|transparencydisplay|qpmode|selectioncycling|osnap {on,modes}` (`osmode` 3 for end+mid), `isodraft {on,plane}`, `isoplane {plane}`, `dsettings {snapunit,gridunit,polarang}` (returns the settings), `sysvars {}`, `drawing.inspect {entities,limit}`, `shapes {type}` (area, centroid, perimeter), `usage {type:"layers"}` (used/unused/empty per layer), `loops {}` (closed loops from loose lines: a triangle of 3 lines gave area 50, ccw), `qselect.info {}` (types with counts and filterable properties).
- **Selection, clipboard, undo:** `selectall` + `erase.selection`, `isolateobjects|hideobjects {handles}` + `unisolateobjects {}`, `cutclip`, `cutbase`/`copybase {handles,base}`, `pasteblock {at}` (inserts a block `A$C…`), **`pasteorig` only works into a DIFFERENT drawing**, `u {}`/`undo {count}`, `redo {count}`, `mredo {all:true}` (named the redone command).
- **LISP and aliases:** `lisp {code:"(+ 1 2)"}` → `value:"3"`, `(defun c:foo …)` defines a command, `appload {name,text}` loads a .lsp source (`commands:["BAR"]`), `aliasedit {set:{"zz":"circle"}}` / `reinit {}`.
- **Housekeeping:** `-xref {option:"?"}` lists xrefs, `drawingrecovery {action:"list"}` (empty), `recover {path}` errors cleanly on a missing file, `document.switch {index}`, `closeall`. **Not available in 0.13.0:** `3dorbit` ("CADCraft draws in 2D (plan view) only") and `share` (use `export` or `publish`).
- Not run: `arc.continue` after an arc, `-plottermanager`, `-xref` attach/detach options (see Round 4 in `drafting-features.md` for `xattach`), `compare*` and `grip.*` (mouse/UI tools), `ai_deselect`.
